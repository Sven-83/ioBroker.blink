## Kurzfazit

Die Neufassung ist klar geschichtet (API ↔ Modell ↔ Lifecycle) und in den sicherheitsrelevanten Punkten strenger als
das Template: Sitzung, wartender Login und Geräte-ID liegen per `this.encrypt()` in States, Tokens gehen nur an
`*.immedia-semi.com` über https, der Livebild-Server ist standardmäßig aus, lauscht auf `127.0.0.1`, verlangt ein
zufälliges Token je Sitzung, und das selbstsignierte Zertifikat der Stream-Server ist fest hinterlegt statt die
Prüfung abzuschalten. Befehle werden zurückgelesen, alle Cloud-Anfragen laufen nacheinander in genau einer
Timer-Kette mit Jitter und Backoff; Bilder und Clips haben eine Aufbewahrungsfrist, Weitergabe an Telegram gibt es
nur als Text und nur per Opt-in. 280 Unit-, 61 Paket- und 59 Integrationstests gegen eine nachgebaute Blink-Cloud
sind grün, die Kernfunktionen laufen seit dem 09.11. auf dem Pi.

Die Befunde betrafen vor allem Repochecker-Punkte (Node 26 in der CI, README nur Englisch, 2FA-Code nicht
verschlüsselt, fehlende Übersetzungen), zwei Lifecycle-Details (`info.connection` beim Beenden,
`extendObjectAsync`), Seriennummern als States und den fehlenden MIT-Hinweis auf die Referenz. Viele
Repochecker-Fehler entstehen nur, weil auf npm unter `iobroker.blink` ein fremder Adapter (Pischleuder1, 0.0.40)
steht; da dieser Adapter bewusst ohne npm und Tags aus `main` installiert wird, sind sie nicht behebbar (N7).

**Fundstelle:** `.github/workflows/test-and-release.yml`

```yaml
name: Test
...
      - uses: actions/checkout@v5
      - uses: actions/setup-node@v5
...
        node-version: [22.x, 24.x]
```

Repochecker 5.24.0: **E3025** (Node 26 fehlt), **W3004** (Name muss „Test and Release“ sein). Dependabot hatte
`checkout`/`setup-node` v7 bereits als PR #1/#2 gemeldet.

**Fix:** `name: Test and Release`, Matrix `[22.x, 24.x, 26.x]`, `actions/checkout@v7`, `actions/setup-node@v7`.
Damit sind PR #1 und #2 überholt.

### H2 – README nicht nur Englisch – ✅ behoben

**Fundstelle:** `README.md` (Abschnitt „Deutsch“). Repochecker **E6015**.

**Fix:** `README.md` nur Englisch, deutsche Anleitung in `docs/de/README.md` (wie liebherr-home). Dabei ergänzt:
Hinweis auf das gleichnamige fremde npm-Paket, Voraussetzungen, vollständige Datenpunkt-Tabelle (Bewegung, Clip,
Batterie, Bild, Livebild), alle Einstellungen, Livebild-`sendTo`, bekannte Grenzen (B.14.3, B.14.4, B.14.8),
Herkunft/Disclaimer, Badge „Test and Release“ (B.14.6). „Planned features“ → „Features“ (alles umgesetzt).
