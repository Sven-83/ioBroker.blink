# Security Policy

## Supported versions

Security fixes are made for the latest version on the `main` branch only. Please update before reporting.

## Reporting a vulnerability

**Please do not open a public issue for security problems.**

Report vulnerabilities privately via GitHub:
[Report a vulnerability](https://github.com/Sven-83/ioBroker.blink/security/advisories/new)
(repository tab *Security* → *Report a vulnerability*).

Please include:

- the adapter version and your js-controller and Node.js versions
- what an attacker can do and how to reproduce it
- logs only after removing tokens, e-mail addresses, serial numbers and camera images

## What happens next

- You get a first answer within 14 days.
- Once the problem is confirmed, a fix is prepared in a private security advisory and released as soon as possible.
- You are credited in the advisory and the changelog unless you prefer otherwise.

## Scope

In scope: this adapter.

Out of scope: the Blink cloud service, cameras and apps (please contact Blink/Amazon), and the ioBroker
js-controller and admin (please report to the ioBroker project).
